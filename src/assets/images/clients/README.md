# Logos de Clientes

Esta carpeta contiene los logos de las empresas con las que MeBu ha trabajado.

## Instrucciones

Coloca aquí los logos de los clientes con los siguientes nombres:
- `client-1.png` o `client-1.svg`
- `client-2.png` o `client-2.svg`
- `client-3.png` o `client-3.svg`
- `client-4.png` o `client-4.svg`

## Recomendaciones

- **Formato**: Preferiblemente PNG o SVG con fondo transparente
- **Tamaño**: Aproximadamente 200x100px
- **Fondo**: Transparente o blanco
- **Calidad**: Alta resolución para verse bien en pantallas retina
